## 🚨 v3.1.0 アップデートハイライト：警察追跡・ドリフト・ハザード・パッシング大刷新！

ユーザー様からのフィードバックに基づき、理不尽だった警察の追跡挙動を完全に見直し、ドリフト・ハザード・パッシングに爽快で戦術的なゲーム機能を実装しました！

### 1. 🚓 警察追跡バランス刷新＆最高速度リミッター（逃走可能に！）
- **最高速度上限を設定**:
  - 一般警らパトロールカー: 最高 **270 km/h**
  - 高速隊インターセプター: 最高 **310 km/h**
  - プレイヤーの速度に合わせて理不尽にどこまでも追いついてくる従来の仕様を完全撤廃！
  - プレイヤーが300km/h超の限界走行やNOS/ミニターボ加速を駆使すれば、パトカーを完全に引き離して逃げ切ることが可能になりました！
- **操舵ディレイ・慣性の導入（フェイントで回避可能！）**:
  - パトカーの追従AIに人間らしい反応遅延と車体慣性を付与。
  - 突進してくるパトカーに対して、直前で急激なレーンチェンジやドリフトで車体を振ることで、パトカーをオーバーシュートさせて綺麗に躱すことができます！
- **💨 逃走メーター（PURSUIT ESCAPE GAUGE）**:
  - パトカーとの車間距離を45m以上離し続けると、画面下部の「逃走メーター」が上昇。
  - 100%まで距離を維持できれば「逃走成功（EVADED）」となり、**+5,000 PTS** の特大ボーナス獲得＆手配度が減少！パトカーは追跡を諦めて通常走行に戻ります。

### 2. 💥 ギミック・道路罠によるパトカー撃破（TRAP TAKEDOWN）
- **パトカーが無敵ですり抜けるバグを完全解消！**:
  - 道路上のドラム缶、スパイクマキビシ、崩落巨石、落下丸太、オイル、高圧火柱、クラッシャーなどのギミック罠が、パトカーにも完全ヒットするように判定を拡張！
- **映画のようなパトカー撃退テイクダウン**:
  - **🛢️ 爆発ドラム缶**: パトカーをドラム缶に突っ込ませると大爆発！パトカーが空中へ吹き飛び一撃撃破（+4,000 PTS & スローモーションカメラ）！
  - **⛓️ スパイク帯**: パトカーのタイヤが破裂！コントロールを失いガードレールへ激突大破（+3,500 PTS）！
  - **🪨 崩落巨石 / 🪵 落下丸太**: パトカーのルーフ・ボンネットを直撃圧壊（+4,500 PTS）！
  - **💧 オイル漏れ**: パトカーが360度大スピンして後続車を巻き込み自滅（+3,000 PTS）！
  - **🔥 高圧火柱**: タイミングよく誘い込めばパトカーが火柱に包まれ炎上撃沈（+4,000 PTS）！

### 3. 🔥 ドリフト刷新＆ミニターボ加速システム [X]
- **50km/h以上で即座にパワースライド開始**:
  - [X]キー（または画面のDRIFTボタン）を押すと、即座に後輪グリップが滑り出し、鋭いカウンターステアでコーナーや車間をすり抜ける本格ドリフトが発動！
  - 旋回性能が1.55倍に向上し、後輪から猛烈な白煙タイヤスモークと火花が噴出します。
- **2段階ミニターボチャージ＆ロケット噴射**:
  - **0.7秒ホールド**: 青色火花とともに【青色ミニターボ (Blue Mini-Turbo)】が待機完了！
    - キーを離すと **+32 km/h** のダッシュ加速噴射＆NOS回復！
  - **1.6秒ホールド**: 黄金火花とともに【黄金スーパーミニターボ (Gold Super-Turbo)】が待機完了！
    - キーを離すと **+55 km/h** の爆発的ロケット加速噴射＆NOS大幅回復！

### 4. ⚡ パッシング目眩まし戦術 [F]
- [F]キーでハイビームを照射すると、前走車が素早く道を譲るだけでなく、**パトカーの追跡ドライバーの視界を2秒間奪う（目眩ましフラッシュ）**ことができます！
- 目眩ましされたパトカーは蛇行・減速して追跡を一時中断するため、至近距離に迫られた絶体絶命の瞬間からの脱出や、パトカーを罠に誘導する戦術として威力を発揮します（成功時 +800 PTS）。

### 5. 🛡️ ハザード緊急エアブレーキ＆リア防壁カウンター [Z]
- **レースゲームにおけるハザードの存在意義を一新！**:
  - **緊急エアブレーキ**: [Z]キーを押すと、ハザード4灯点滅とともに強力な空気抵抗ブレーキが作動。車輪をロックさせずに急減速し、目の前の障害物や玉突き事故を回避可能！
  - **リア電磁防壁カウンター**: ハザード作動中は、車体後方に強力なエネルギー防壁を展開。
    - この状態で後方からパトカーや煽り運転車が突進・追突してきた場合、**プレイヤーはノーダメージ（0ダメージ）**！
    - 追突してきたパトカーは防壁の強烈な反発衝撃波でフロントが大破し、空中へ吹き飛んで撃破されます（+4,000 PTS & 手配度低下 & NOS全回復）！

## 🎮 操作方法 (Keyboard & Touch)

| キー | 機能 | 説明 |
| :--- | :--- | :--- |
| **↑ / W** | アクセル | 加速 |
| **↓ / S** | フットブレーキ | 減速・後退 |
| **← / → (A / D)** | ステアリング | 左右操舵 |
| **Space / Shift** | NOS ニトロブースト | 猛烈な排気炎と超加速噴射 |
| **X** | **ドリフト＆ミニターボ** | **長押しでチャージ、離して爆発的ロケットダッシュ噴射！** |
| **F** | **パッシング / 目眩まし** | **前走車の避譲＆パトカーを2秒間目眩まし無力化！** |
| **Z** | **ハザード防壁＆エアブレーキ** | **緊急急減速＆後方からの追突パトカーを返り討ち撃破！** |
| **H** | クラクション | 前走車威嚇ホーン |
| **C** | カメラ切り替え | 追従・ボンネット・コックピット・シネマティック |
| **R** | リペア | 車体軟体変形・タイヤパンク全修復 |
| **B** | スケルトン表示 | 車体内部の Node-Beam 応力骨格を透過表示 |
| **T** | スローモーション | 0.25倍速の超精密物理観察 |

## 📦 ビルド・パッケージング

```bash
# 依存関係インストール
npm install

# 動作確認スモークテスト
npm run smoke

# Windowsインストーラーおよびポータブルexeの生成
npm run dist
```
生成されるバイナリ：
- `dist/Crashoria-Ultimate-Road-Adventure-Portable-v3.1.0.exe` (インストール不要の単一実行ファイル)
- `dist/Crashoria-Ultimate-Road-Adventure-Setup-v3.1.0.exe` (デスクトップショートカット付きインストーラー)
