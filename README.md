## 💥 破壊のリアルさ極限強化（BeamNG.drive / Wreckfest レベル）

前バージョンから物理変形・クラッシュ演出・サブシステム破壊を極限まで強化しました：

1. **多重アコーディオン座屈＆高ピークV字ボンネット折れ曲がり**:
   - 衝突衝撃がクランプルゾーンを伝播し、前後方向の圧縮で鋼板が波打つように鋭角に折れ曲がります（Accordion Folding）。
   - 正面衝突時はボンネット中央が実車衝突同様に `+0.9m` 以上跳ね上がってV字に座屈し、視界を遮ります。
2. **アクスル完全破断＆転がるホイール（独立剛体物理）**:
   - 重大な角部・縁石ヒットでサスペンションアームがボキリと完全破断！
   - タイヤとアルミホイールが `Cannon.js` の独立剛体として路面を跳ね・転がって飛散。
   - 車体側は剥き出しのブレーキローターがアスファルトに接地し、**激しい路面火花と激越な金属摩擦音**を響かせながら片側に激しくステアリングが取られます！
3. **引きずるバンパーの火花接地**:
   - 衝撃でバンパーのクリップが片側だけ破損すると、バンパーが路面に擦れながら大量の火花を撒き散らして走行。さらなる衝撃で完全に脱落します。
4. **強化安全ガラスのモザイク粉砕＆飛散**:
   - フロントガラスやサイドウィンドウが衝撃で粉砕テクスチャ化し、車内・車外へ無数のキラめく3Dガラス破片となって爆散します。
5. **冷却水蒸気噴射・オイル流出＆エンジン火災・二次誘爆**:
   - ラジエーター貫通で高圧の緑色クーラント水蒸気がモクモクと噴出。
   - エンジン損傷でオイルパンが割れ、路面に黒いオイル痕が拡大。
   - 油温・水温が限界を超えるとエンジンルームから激しい炎と黒煙が噴き上がり、最終的には燃料タンクが二次誘爆を起こして大爆発します！
6. **方向性スクリーンシェイク＆ゲームパッド振動**:
   - 衝突ベクトルに応じた激しい画面揺れと、Xbox/PSコントローラーのデュアルモーター振動フィードバックを完全実装。

## 🎮 操作方法まとめ

- **ステアリング**: `[←] [→]` または `[A] [D]`（ゲームパッド左スティック）
- **アクセル / ブレーキ**: `[↑] [↓]` または `[W] [S]`（ゲームパッド RT / LT）
- **ツイン・ニトロ (NOS)**: `[Space]`（青色アフターバーナー加速）
- **スローモーション (Bullet-Time)**: `[Shift]`（0.28倍速タイムワープ）
- **BeamNG 構造ノード応力表示**: `[V]`（骨格フレームの歪みカラー可視化）
- **即時板金・アクスル完全修復**: `[R]`（潰れた頂点とホイールを新車状態へ瞬時復元）
- **威嚇ホーン＆パッシング**: `[H]`（前走車を威嚇してレーンを空けさせる）
- **実動ワイパー**: `[W]`（雨天走行時の雨粒払拭）
- **車載ラジオ切替**: `[M]`（5局のBGM局切替）
- **カメラ視点切替**: `[C]`（チェイス / ロー / コックピット車内 / ヘリ俯瞰）
- **フルスクリーン切替**: `[F11]`
