## ✨ 新機能一覧（v2.0 新搭載）

1. **🟢 BeamNG 構造ノード・応力スケルトン表示 (`V` キー)**
   - 車体内部の28ノード・70本以上の構造フレーム（クランプルゾーン・ピラー・サブフレーム）を3Dオーバーレイ表示。無負荷（緑）→高応力（黄/橙）→塑性変形（赤）がリアルタイムに変化します。
2. **🧪 BeamNG 物理クラッシュ実験場モード (Crash Sandbox)**
   - ゲームオーバーなし！走行中に画面上部の実験場ツールバーから**「⚙️ 巨大油圧クラッシャー」「🧱 衝突試験バリア」「📐 大ジャンプ台」「🛢️ 爆発ドラム缶」**をいつでも前方に配置して軟体クラッシュ実験を行えます。
3. **🔧 即時板金・シャシー完全修復 (`R` キー)**
   - BeamNG.driveでお馴染みのリペア機能。グシャグシャに潰れたボディ頂点・歪んだタイロッド・パンクしたタイヤをワンキーで新車状態へ復元します。
4. **⏱️ バレットタイム・スローモーション (`Shift` キー)**
   - 時間を `0.28倍速` にスロー化！衝突の瞬間に金属が折れ曲がる様子を観察したり、高難易度の高齢者逆走車を映画のようにスローで華麗にかわせます。
5. **🔥 ツイン・ニトロブースト (`Space` キー)**
   - 4本出しチタンマフラーから蒼いアフターバーナー炎を噴射し、強烈な加速GとFOVワープで一気に最高速へ到達します。
6. **📢 威嚇ホーン＆ハイビームパッシング (`H` キー)**
   - 前方を走る一般車や煽り運転車にクラクションとパッシングを浴びせ、車線を空けさせることができます。

## 📦 Windows アプリ版の起動方法

GitHub Releases から以下のいずれかをダウンロードしてそのまま起動できます：
- **`ApexOverdrive-BeamNG-Portable-v2.0.0.exe`**: インストール不要の単体起動ポータブル版
- **`ApexOverdrive-BeamNG-Setup-v2.0.0.exe`**: デスクトップショートカットを作成するインストーラー版

### 開発環境からの起動・ビルド
```bash
npm install
npm start       # Windows アプリを起動
npm run dist    # dist/ フォルダに Windows EXE をビルド
```
