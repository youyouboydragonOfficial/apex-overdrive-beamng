## ⚡ v2.6.0 新機能：パッシング連打＆ドライバー心理リアクション物理

「パッシングを連打しても強制的にどかず、人間味のあるリアルな運転ミスや逆上を引き起こす」新システムを完全実装しました！

### 1. 🔘 連打しても強制的には退かない！個性別・確率的心理リアクション
- **👵 高齢者ドライバー (枯葉・もみじマーク車 / 逆走車)**:
  - 後方や正面からの執拗なパッシングに眩惑・驚愕し、パニック状態に陥ります：
    - **40% 確率: 【パニック急ブレーキ（踏み間違い）】**: 驚いてブレーキを踏み込み、激しいタイヤスモークとスキッド音を上げながら急制動！後続車を巻き込む大事故の原因に。
    - **25% 確率: 【過大操舵・蛇行ガードレール激突自爆】**: 慌ててハンドルを切りすぎて蛇行スピンし、高速道路の側壁・ガードレールに激突！軟体板金が大破し火花を散らして自爆。
    - **25% 確率: 【進行方向見失い・車線跨ぎ低速硬直】**: パニックで進路を見失い、ハザードや誤ったウィンカーを点滅させながら車線境界をまたいで35km/hで這うように走行。
    - **10% 確率: 【慎重に退避】**: ハザードを焚きながらゆっくり左車線へ避譲。
- **💢 煽り運転者 (黒塗りセダン・大型GTウイング装着車)**:
  - **連打しても絶対に素直に退きません！** 威嚇パッシングを受けるとプライドを刺激されて激怒（AGGRO上昇）：
    - **45% 確率: 【逆上報復ブレーキチェック】**: プレイヤーの鼻先に急激に割り込み、故意にフルブレーキを踏んで追突させようとします！
    - **35% 確率: 【幅寄せ蛇行進路妨害ブロック】**: プレイヤーが左右どちらの車線に移ろうとしても、その進路を塞ぐように蛇行して追い越しを完全妨害！
    - **20% 確率: 【超急加速バトル逃走】**: 200km/h超までフルスロットル急加速し、排気炎を噴き上げながら爆走逃走。
- **🚨 パトカー (POLICE)**:
  - パトカー後方からの連続パッシングやホーン威嚇は「警察妨害・威嚇運転」とみなされ、**WANTED ★+1 指名手配**が即座に発動！ルーフの赤色灯が点滅しサイレン追跡が始まります。
- **🤝 一般車**:
  - 50%が左ウィンカーを出してスムーズに道を譲り、30%はマイペース維持（無視）、20%は突然の光に驚いて急減速します。

## 💥 破壊のリアルさ極限強化（BeamNG.drive / Wreckfest レベル）

1. **多重アコーディオン座屈＆高ピークV字ボンネット折れ曲がり**:
   - 衝突衝撃がクランプルゾーンを伝播し、前後方向の圧縮で鋼板が波打つように鋭角に折れ曲がります（変形許容量 1.65m）。
   - 正面衝突時はボンネット中央が実車衝突同様に `+0.9m` 以上跳ね上がってV字に座屈し、視界を遮ります。
2. **アクスル完全破断＆転がるホイール（独立剛体物理）**:
   - 重大な角部・縁石ヒットでサスペンションアームがボキリと完全破断！
   - タイヤとアルミホイールが `Cannon.js` の独立剛体として路面を跳ね・転がって飛散。
   - 車体側は剥き出しのブレーキローターがアスファルトに接地し、**激しい路面火花と激越な金属摩擦音**を響かせます！
3. **引きずるバンパーの火花接地**:
   - 衝撃でバンパーのクリップが片側だけ破損すると、バンパーが路面に擦れながら大量の火花を撒き散らして走行。
4. **強化安全ガラスのモザイク粉砕＆飛散**:
   - フロントガラスやサイドウィンドウが衝撃で粉砕テクスチャ化し、車内・車外へ無数のキラめく3Dガラス破片となって爆散します。
5. **冷却水蒸気噴射・オイル流出＆エンジン火災・二次誘爆**:
   - ラジエーター貫通で高圧の緑色クーラント水蒸気がモクモクと噴出。
   - エンジン損傷でオイルパンが割れ、路面に黒いオイル痕が拡大。
   - 油温・水温が限界を超えるとエンジンルームから激しい炎と黒煙が噴き上がり、最終的には燃料タンクが二次誘爆を起こして大爆発します！
6. **方向性スクリーンシェイク＆ゲームパッド振動**:
   - 衝突ベクトルに応じた激しい画面揺れと、Xbox/PSコントローラーのデュアルモーター振動フィードバックを完全実装。
